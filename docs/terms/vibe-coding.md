# vibe coding: where it came from

Vibe coding is a name credited to Andrej Karpathy in February 2025 for building software by talking to a large language model in plain language instead of writing the code yourself. It now mostly means describing what you want, letting AI agents write the code, and judging the result by whether it runs, often with little review of the code. That practice is now widely applied in education and medicine and widely criticized for security and maintainability risks. The 2019 and 2020 entries refer to AI-era vibe coding and look misdated.

## Eras

- **2025–2025 · Conversational AI programming paradigm**: Right after its coining, the term named a new way of programming in which people, including non-programmers, describe intent in natural language and an LLM writes the code, framed mainly as a democratizing and rapid-prototyping approach.
- **2026–2026 · Agent delegation under scrutiny**: The term came to mean handing implementation to autonomous coding agents with minimal review, and it was increasingly treated as a baseline to benchmark, secure, govern, or move beyond toward spec-driven and agentic engineering.

- **2025 · popularized**: [Vibe coding: programming through conversation with artificial intelligence](https://doi.org/10.48550/arxiv.2506.23253). This highly cited paper framed vibe coding as an emerging paradigm of writing code by conversing with LLMs.
  - > We examine "vibe coding": an emerging programming paradigm where developers primarily write code by interacting with code-generating large language models rather than writing code directly. (Advait Sarkar et al., 2025)
- **2025 · applied**: [From technology adopters to creators: Leveraging AI-assisted vibe coding to transform clinical teaching and learning](https://doi.org/10.1080/0142159x.2025.2488353). It carried the term into clinical education as a no-code way for educators to build their own tools.
  - > To address these challenges, we introduce vibe coding, a novel AI-assisted, no-code development approach that enables educators to create interactive, customisable learning simulations without programming expertise. (Minyang Chow et al., 2025)

- **2025 · redefined**: [Vibe Coding vs. Agentic Coding: Fundamentals and Practical Implications of Agentic AI](https://doi.org/10.48550/arxiv.2505.19443).   - > The advancement of large language models (LLMs) has catalyzed a paradigm shift from code generation assistance to autonomous coding agents, enabling a novel development methodology termed "Vibe Coding" where developers validate AI-generated implementations through outcome observation rather than line-by-line code comprehension.
