# vibe coding: where it came from

据证据，“vibe coding”一词由Andrej Karpathy于2025年2月提出，随后迅速在软件工程、教育和医学等领域被定义、研究和应用。如今它主要指用户以自然语言描述目标，由AI（日益是自主编码代理）生成并迭代代码、往往很少审阅底层代码的开发方式，并常与代理式工程、规范驱动开发相对照。

## Eras

- **2025–2025 · 命名、定义与跨领域试用**: 该词刚被提出，学界忙于界定它是以自然语言对话驱动大语言模型写代码的新范式，并在教育、医学和原型开发中试用，同时开始关注代码质量与安全问题。
- **2026–2026 · 代理化、验证与治理**: 该词更多指把实现委托给自主编码代理、凭运行结果而非代码审阅来验收的做法，研究重心转向安全基准、形式验证、规范驱动开发以及向“代理式工程”的过渡。
