# world model: where it came from

“世界模型”在本证据中最早见于20世纪80年代的AI规划与机器人研究，指系统用于规划和导航的环境表示；1991年前后开始指强化学习中可学习的、能预测环境变化的模型。2018年以来，尤其是2023年后，它主要指能根据动作预测或生成未来观测的大规模学习模型，广泛用于自动驾驶、机器人和大语言模型推理，近年论文数量随之激增。

12954 papers in OpenAlex use this term (1899–2026); 160 sentences read.

Follows: 本时间线追踪人工智能中的“世界模型”：智能体（或模型）内部对环境的表示，用来预测状态变化并据此规划或决策。它从经典AI规划和机器人中的环境表示，发展为强化学习中学到的预测模型，再到如今的生成式视频世界模型和大语言模型的世界模型。

## Eras

- **1983–1990 · 经典AI与机器人表示**: 世界模型指规划系统和机器人用于推理、导航的环境表示，通常手工构建，或由传感器数据实例化为符号或栅格形式。
- **1991–2017 · 强化学习中的学习模型**: 世界模型开始指智能体从经验中学到的环境预测模型，用于规划和探索，同时机器人领域仍沿用环境表示的用法。
- **2018–2022 · 深度学习世界模型**: 世界模型指用神经网络学习的压缩时空表示，智能体可以在“想象”中学习行为，以提高样本效率。
- **2023–2026 · 生成式与大模型世界模型**: 世界模型扩展为大规模生成式视频或多模态基础模型，以及大语言模型内部的世界表示，广泛用于自动驾驶、机器人和智能体，其是否真正理解物理规律也引发争论。

## Milestones

- **1983 · origin**: [Planning using a temporal world model](https://openalex.org/W166266902). 在年代可靠的证据中，这是最早以AI规划语境使用“世界模型”的文献，并指出现有问题求解系统受制于不完善的世界模型。
  - > Current problem solving systems are constrained in their applicability by inadequate world models. (James F. Allen et al., 1983)
- **1989 · applied**: [Stereo vision and navigation in buildings for mobile robots](https://doi.org/10.1109/70.88100). 移动机器人借助立体视觉、里程计和碰撞传感器实例化符号世界模型，把这一概念带入机器人感知与导航领域。
  - > The omnidirectional mobile robot uses stereo vision, odometry, and contact bumpers to instantiate a symbolic world model. (David Juris Kriegman et al., 1989)
  - > We will show how new constraint information, usually obtained by measurement, can be used to update the world model of relationships consistently, and in some situations, optimally. (Randall K. Smith et al., 1988)
- **1991 · redefined**: [A Possibility for Implementing Curiosity and Boredom in Model-Building Neural Controllers](https://doi.org/10.7551/mitpress/3115.003.0030). 提出由神经控制器在线学习的自适应世界模型，使世界模型从预先构建的表示转变为可学习的预测模型。
  - > This paper introduces a framework for `curious neural controllers' which employ an adaptive world model for goal directed on-line learning. (Jürgen Schmidhuber, 1991)
  - > Using some sort of adaptive predictive world model, they improve their ability to answer questions such as what happens if I do this or that? (Jürgen Schmidhuber, 2006)
- **1991 · popularized**: [Dyna, an integrated architecture for learning, planning, and reacting](https://doi.org/10.1145/122344.122377). Dyna让规划利用学习得到的概率世界模型，这一思路在证据中被广泛引用，并延续到后来的Deep Dyna-Q。
  - > Planning is incremental and can use the probabilistic and ofttimes incorrect world models generated by learning processes. (Richard S. Sutton, 1991)
- **2018 · popularized**: [World Models](https://doi.org/10.5281/zenodo.1207631). 以“世界模型”为题，展示可无监督训练的压缩时空环境表示，成为后续研究的高引用核心文献。
  - > Our world model can be trained quickly in an unsupervised manner to learn a compressed spatial and temporal representation of the environment. (David Ha et al., 2018)
- **2019 · popularized**: [Dream to Control: Learning Behaviors by Latent Imagination](https://doi.org/10.48550/arxiv.1912.01603). Dreamer系列让智能体在学到的世界模型中通过“想象”学习行为，确立了这一主流范式，并被后续机器人工作采用。

  - > World models facilitate such generalization and allow learning behaviors from imagined outcomes to increase sample-efficiency. (Danijar Hafner et al., 2020)
- **2023 · applied**: [Reasoning with Language Model is Planning with World Model](https://doi.org/10.18653/v1/2023.emnlp-main.507). 把世界模型的概念引入大语言模型推理，认为大语言模型缺乏预测世界状态的内部世界模型。
