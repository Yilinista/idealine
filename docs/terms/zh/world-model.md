# world model: where it came from

在现有证据中，“world model”最早见于20世纪30至60年代的相对论宇宙学，指描述整个宇宙结构与膨胀的“世界模型”。80年代起它进入人工智能与机器人领域，表示智能体对环境的内部表示；如今它主要指能根据动作预测未来状态、可用于在“想象”中规划和训练的学习型（常为生成式视频）模型。

## Eras

- **1934–1982 · 宇宙学中的世界模型**: 指相对论宇宙学中对整个宇宙（如膨胀、稳态模型）的数学模型，用于与红移、源计数等观测比较。
- **1983–2017 · 智能体的环境内部表示**: 在规划、机器人和自然语言系统中，世界模型指系统对环境的（常为符号或栅格的）内部表示，并逐渐出现由学习得到的预测模型；宇宙学用法（如膜世界模型）同时延续。
- **2018–2022 · 深度强化学习中的学习型世界模型**: 指用神经网络从经验中无监督学习的环境压缩时空表示，智能体可在其“想象”中规划和学习行为。
- **2023–2026 · 生成式基础世界模型**: 指大规模生成式（视频、多模态、语言）模型，能根据动作预测未来观测，用于自动驾驶、机器人和大语言模型推理规划，并被视为通向通用智能的路径。
