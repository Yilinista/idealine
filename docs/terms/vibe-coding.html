vibe coding

Vibe coding is a name credited to Andrej Karpathy in February 2025 for building software by talking to a large language model in plain language instead of writing the code yourself. It now mostly means describing what you want, letting AI agents write the code, and judging the result by whether it runs, often with little review of the code. That practice is now widely applied in education and medicine and widely criticized for security and maintainability risks. The 2019 and 2020 entries refer to AI-era vibe coding and look misdated.
